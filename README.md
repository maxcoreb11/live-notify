# บอท Telegram แจ้งเตือนตารางไลฟ์สด (11 PRO NO FAKE)

รันอัตโนมัติบน **GitHub Actions** — ไม่ต้องมีคอมพิวเตอร์หรือเซิร์ฟเวอร์ของตัวเอง
ตั้งค่าได้ทั้งหมดผ่านเว็บเบราว์เซอร์บน iPad (ใช้แอป GitHub หรือ Safari ก็ได้)

ระบบจะเช็คตารางทุก 5 นาที แล้วส่งข้อความเข้ากลุ่ม Telegram ล่วงหน้าก่อนไลฟ์แต่ละคู่
(ค่าเริ่มต้น: 60, 30, 10, 0 นาทีก่อนเริ่ม)

## ไฟล์ในชุดนี้

| ไฟล์ | หน้าที่ |
|---|---|
| `schedule.json` | ตารางไลฟ์เดือนสิงหาคม 2569 (51 รายการ) — แก้ไข/เพิ่มเองได้ผ่านเว็บ GitHub |
| `needs_review.json` | 4 รายการที่ยังไม่มีเวลาแน่นอนในไฟล์ต้นฉบับ (รอประกาศ) |
| `import_schedule.py` | แปลงตาราง Excel เดือนใหม่ให้เป็น `schedule.json` อัตโนมัติ (รันในเครื่องตัวเอง) |
| `notify_bot.py` | สคริปต์หลัก เช็คตารางแล้วส่งรูปแบนเนอร์ + ข้อความเข้า Telegram |
| `banner.py` | สร้างรูปแบนเนอร์แจ้งเตือน (ใส่ชื่อคู่แข่งขัน/เวลาลงในรูปอัตโนมัติ) |
| `assets/fonts/*.ttf` | ฟอนต์ไทยที่ใช้วาดตัวหนังสือในรูปแบนเนอร์ (ต้องอัปโหลดด้วย ห้ามลืม) |
| `.github/workflows/notify.yml` | ตัวสั่งให้ GitHub รันสคริปต์ทุก 5 นาทีอัตโนมัติ |
| `config.example.json` | ใช้เฉพาะกรณีอยากทดสอบในเครื่องคอมเอง (ไม่จำเป็นถ้าใช้ GitHub Actions) |

## รูปแบนเนอร์แจ้งเตือน

ทุกครั้งที่แจ้งเตือน บอทจะสร้างรูปภาพขึ้นใหม่อัตโนมัติ (ไม่ใช่ข้อความเปล่า) โดยมี:
- ป้าย "LIVE NOW" (สีพื้น) หรือ "อีก N นาทีถ่ายทอดสด" (ขอบสี) มุมซ้ายบน
- ชื่อประเภทกีฬา มุมขวาบน
- ชื่อรายการ + คู่แข่งขันตัวใหญ่กลางรูป
- เวลาไทย/วันที่ ด้านล่าง
- สีธีมเปลี่ยนตามประเภทกีฬา (ONE = ส้มแดง, VNL = ฟ้า, บอล/บอลโลก = เขียว, SEA V Cup = เหลืองทอง, มวยไทย = ส้ม, UFC = แดงเข้ม)

ส่วนข้อความใต้รูปจะมีช่องที่ถ่ายทอด (`ดูที่ไหน`) และผู้รับผิดชอบ (`P'เปรี้ยว`) ต่อท้ายให้ด้วย ถ้าตารางเดือนนั้นมีข้อมูล

ถ้าสร้างรูปไม่สำเร็จด้วยเหตุผลใดก็ตาม บอทจะ fallback ไปส่งเป็นข้อความล้วนแทนอัตโนมัติ ไม่ทำให้แจ้งเตือนขาดหาย

## ขั้นตอนติดตั้ง (ทำบน iPad ล้วน ๆ)

### 1. สร้างบอท Telegram
1. เปิดแชทกับ **@BotFather** ใน Telegram
2. พิมพ์ `/newbot` แล้วตั้งชื่อบอทตามต้องการ
3. จะได้ **bot token** มา (หน้าตาแบบ `123456789:AAxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`) — เก็บไว้ก่อน

### 2. หา Chat ID ของกลุ่มพนักงาน
1. สร้างกลุ่ม Telegram แล้วเชิญบอทเข้ากลุ่ม
2. ส่งข้อความอะไรก็ได้ในกลุ่ม 1 ข้อความ
3. เปิด Safari ไปที่ (แทน `<TOKEN>` ด้วย token จริง):
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
4. หาเลข `"chat":{"id": -1001234567890, ...}` — นี่คือ chat_id (กลุ่มมักขึ้นต้นด้วยเครื่องหมายลบ)

### 3. สร้าง GitHub repo (ถ้ายังไม่มี)
1. สมัคร/ล็อกอิน github.com (ใช้ Safari หรือแอป GitHub)
2. กด **New repository** → ตั้งชื่อ เช่น `live-notify-bot` → เลือก **Private** (แนะนำ) → Create

### 4. อัปโหลดไฟล์ทั้งหมดเข้า repo
1. ในหน้า repo กด **Add file → Upload files**
2. ลากไฟล์ทั้งหมดที่ให้ไปนี้เข้าไป (คงโครงสร้างโฟลเดอร์ให้ตรง):
   - `notify_bot.py`
   - `banner.py`
   - `requirements.txt`
   - `schedule.json`
   - `needs_review.json`
   - `assets/fonts/Kanit-Bold.ttf`
   - `assets/fonts/Kanit-ExtraBold.ttf`
   - `assets/fonts/Kanit-Medium.ttf`
   - `.github/workflows/notify.yml` ← **สำคัญ**: ต้องอยู่ในโฟลเดอร์ `.github/workflows/` พอดี
     (ถ้าอัปโหลดแบบลากไฟล์เดี่ยวแล้ว path ไม่ตรง ให้ใช้ **Add file → Create new file** แล้วพิมพ์ชื่อไฟล์เป็น
     `.github/workflows/notify.yml` เต็ม ๆ ในช่องชื่อไฟล์ — GitHub จะสร้างโฟลเดอร์ให้เอง แล้ววางเนื้อหาไฟล์ตาม)

   > เคล็ดลับ: ลากทั้งโฟลเดอร์ `assets` และ `.github` เข้าไปในช่อง Upload files พร้อมกันได้เลย
   > GitHub จะรักษาโครงสร้างโฟลเดอร์ย่อยให้อัตโนมัติ
3. กด **Commit changes**

### 5. ตั้งค่า Secrets (เก็บ token อย่างปลอดภัย ไม่ให้ใครเห็น)
1. ในหน้า repo ไปที่ **Settings → Secrets and variables → Actions**
2. กด **New repository secret** สร้าง 2 ตัว:
   - ชื่อ `BOT_TOKEN` ค่า = token จากขั้นตอนที่ 1
   - ชื่อ `CHAT_ID` ค่า = chat id จากขั้นตอนที่ 2

### 6. เปิดใช้งาน Actions
1. ไปที่แท็บ **Actions** ของ repo
2. ถ้าขึ้นให้กด enable workflows ให้กดยืนยัน
3. เลือก workflow **Live Stream Notify** → กด **Run workflow** เพื่อทดสอบรันทันที 1 ครั้ง
4. เช็คในกลุ่ม Telegram — ถ้ามีไลฟ์ที่ใกล้ถึงเวลาตอนทดสอบ จะมีข้อความเด้งเข้ามา
   (ถ้าไม่มีไลฟ์ตรงช่วงเวลานั้นพอดี จะไม่มีข้อความ ซึ่งถือว่าปกติ ไม่ใช่ error)

จากนี้ระบบจะรันอัตโนมัติทุก 5 นาทีตลอด 24 ชม. โดยไม่ต้องเปิดอะไรเพิ่มอีก ✅

## ข้อจำกัดที่ควรรู้
- GitHub Actions cron **รันได้ถี่สุดทุก 5 นาที** (ตั้งถี่กว่านี้ไม่ได้)
- บางช่วงเวลาที่คนใช้ GitHub เยอะ อาจดีเลย์เพิ่มอีก 5-15 นาที — สคริปต์เผื่อช่วงนี้ไว้แล้ว (grace period 20 นาที) เพื่อไม่ให้ "พลาด" การแจ้งเตือนไปเลย แต่ก็หมายความว่าบางครั้งข้อความอาจมาช้ากว่ากำหนดเล็กน้อย โดยเฉพาะแจ้งเตือน "0 นาทีก่อนเริ่ม" — แนะนำให้พึ่งการแจ้งเตือนล่วงหน้า 30-60 นาทีเป็นหลักในการเตรียมทีม
- repo ตั้งเป็น **Private** ได้ฟรี ข้อมูลตารางไลฟ์และ token จะไม่ถูกเห็นจากภายนอก (token เก็บใน Secrets อยู่แล้ว ปลอดภัยสุด)

## สำคัญ: ตรวจสอบก่อนใช้งานจริง
`needs_review.json` มี 4 รายการที่ตารางต้นฉบับยังไม่ระบุเวลาแน่ชัด — ทั้งหมดคือ **เอเอฟเอฟ ซูซูกิ คัพ** ที่ต้องรอดูว่าไทยเข้ารอบหรือไม่:
- รอบรองชนะเลิศ นัดแรก (15 ส.ค.) / นัดสอง (18 ส.ค.)
- รอบชิงชนะเลิศ นัดแรก (22 ส.ค.) / นัดสอง (26 ส.ค.)

รายการเหล่านี้ยังไม่อยู่ใน `schedule.json` — เมื่อรู้เวลาจริงแล้ว เข้าไปแก้ `schedule.json` ผ่านเว็บ GitHub
(กดที่ไฟล์ → ปุ่มดินสอ ✏️ แก้ไข) แล้วเพิ่มรายการแบบนี้ต่อท้าย array:
```json
{
  "date": "2026-08-15",
  "time": "20:00",
  "day_th": "เสาร์",
  "category": "บอล",
  "title": "เอเอฟเอฟ ซูซูกิ คัพ — รอบรองฯ นัดแรก",
  "detail": "ไทย - เวียดนาม",
  "channel": "TrueVisions NOW",
  "free_tv": "เสียเงิน",
  "club": "800 Club",
  "notified_leads": []
}
```
(`channel` / `free_tv` / `club` เป็นตัวเลือกเสริม จะใส่หรือไม่ใส่ก็ได้ — ถ้าใส่จะไปโผล่ในข้อความแจ้งเตือน)

แก้เสร็จกด **Commit changes** ระบบจะดึงค่าล่าสุดไปใช้รอบถัดไปทันที ไม่ต้องทำอะไรเพิ่ม

## การเพิ่มตารางเดือนถัดไป

**วิธีที่ 1 — แปลงจาก Excel อัตโนมัติ (แนะนำ)** ทำในคอมพิวเตอร์ที่มี Python:
```bash
pip install openpyxl
python import_schedule.py "Stream Schedule.xlsx" --sheet "กันยายน 2569"
```
สคริปต์จะเขียนทับ `schedule.json` + `needs_review.json` ให้ใหม่ทั้งไฟล์ โดย:
- อ่านหัวตารางเอง (วันที่ / เวลา (ไทย) / ประเภท / รายการ / คู่ / ดูที่ไหน / ฟรีทีวี? / P'เปรี้ยว)
- ช่องเวลาที่มีหลายรอบ เช่น `18:00 / 20:30` จะถูกแตกเป็น 2 รายการอัตโนมัติ
- แถวที่เวลาเป็น "รอประกาศ" จะถูกส่งไป `needs_review.json` แทน
- รายการที่แจ้งเตือนไปแล้วจะคงสถานะเดิมไว้ ไม่แจ้งซ้ำ

ถ้าอยากเก็บของเดือนเดิมไว้ด้วย ให้เติม `--append` ต่อท้ายคำสั่ง

แปลงเสร็จแล้วอัปโหลด `schedule.json` กับ `needs_review.json` ทับของเดิมใน GitHub

**วิธีที่ 2 — แก้มือ** เปิด `schedule.json` ผ่านเว็บ GitHub แล้วพิมพ์เพิ่มตามโครงสร้างข้างบน หรือส่งไฟล์ Excel เดือนใหม่มาให้ผมแปลงให้ก็ได้

## หมายเหตุด้านความปลอดภัย
- Token อยู่ใน GitHub Secrets เท่านั้น ไม่ปรากฏในโค้ดหรือไฟล์ที่มองเห็นได้ ปลอดภัยแล้ว
- ถ้า token หลุดหรือสงสัยว่ามีคนอื่นเห็น ให้ไปที่ @BotFather พิมพ์ `/revoke` เพื่อสร้าง token ใหม่ แล้วอัปเดตใน Secrets อีกที
